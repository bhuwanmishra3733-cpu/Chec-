# Vampire Browser 🦇

Android browser with:
- Multiple tabs with isolated private browsing
- Local SQLite database (Bookmarks, Notes, History)
- Private Vault with salted PBKDF2 PIN encryption
- Obsidian Dark Material 3 UI

## How to build APK on GitHub Actions
1. Upload this repository to GitHub.
2. Tap the **Actions** tab.
3. Select **Build Vampire Browser APK** -> Tap **Run workflow**.
4. When finished, download `app-debug.apk` under **Artifacts**!
